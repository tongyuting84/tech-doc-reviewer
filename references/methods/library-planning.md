# 文档库规划与生命周期阅读路径方法

- **适用场景**：新建产品文档库、跨文档重构、功能大版本上线、文档库质量评审。
- **输入**：目标读者、典型任务、现有目录、搜索/工单数据、产品依赖、内容 owner、易变事实清单。
- **步骤**：
  1. 按认知、评估、上手、深用、排障列出读者问题，而不是先套栏目。
  2. 建立“阶段—任务—入口文档—支撑文档”映射，找断点、重复和死路。
  3. 为每类事实指定一个权威来源；需要就近复用时保留最小必要内容并指回来源。
  4. 检查新内容的上游入口、下游操作、关联参数/API/FAQ 和返回路径。
  5. 对版本、价格、配额、默认值、限制和截图按变化风险配置 owner、来源、更新时间和复查周期。
  6. 用真实任务走查导航与搜索，记录跳转和失败点；优先修复阻断而非追求统一外观。
- **输出**：阅读路径图、内容地图、权威来源表、重复治理清单、维护计划。
- **禁用/不适用**：单篇小改且无库级证据时，不宣称全局缺失；不要求每篇覆盖生命周期五阶段。

## 可配置治理指标

FAQ Top 5、开头 3 行、7 天闭环、最大跳转次数和新鲜度天数须由团队配置。记录指标定义、样本范围、owner、阈值和生效日期；未配置时只作候选指标。
